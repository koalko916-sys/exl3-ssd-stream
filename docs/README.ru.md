# EXL3 SSD Stream — русская инструкция

Экспериментальный запуск **полной GLM-5.3 UNCENSORED EXL3 3.0bpw** через
подгрузку матриц с SSD. Веса сохраняются в исходном EXL3; вычисления выполняет
ExLlamaV3 1.5.3 с CUDA. Это самостоятельный адаптер, а не C-движок WARP.

Проверено на Windows: RTX 3080 10 ГиБ, Ryzen 5 7500F, RAM 16 ГиБ.
Веса занимают 273 ГиБ. Получен настоящий ответ `2 + 2 = 4`.
**Скорость низкая: 0,073 ток/с, запрос занял 252 с без времени загрузки среды.**
Это один короткий тест; максимальная скорость ПК и качество модели не оценены.

## Установка

Нужны Python 3.13, CUDA-совместимый драйвер NVIDIA и примерно 310 ГиБ
свободного места на SSD для весов, среды и запаса.

```powershell
git clone https://github.com/koalko916-sys/exl3-ssd-stream.git
cd exl3-ssd-stream
powershell -NoProfile -File scripts/install-windows.ps1
.venv\Scripts\hf.exe download Infatoshi/GLM-5.3-UNCENSORED-EXL3-3.0bpw --revision d06b4f42db97c8bb7a8f72e819b979f132e4a721 --local-dir E:\models\glm53-exl3
.venv\Scripts\python.exe -m exl3_ssd_stream --model E:\models\glm53-exl3 --interactive --context 2048 --tokens 256 --report last-response.json
```

Путь `E:\models\glm53-exl3` замените на свою папку с весами.
Скрипт создаёт `.venv` в папке проекта. Он не меняет глобальный Python.
Установщик ещё не проверен на втором чистом ПК.

`/новый` очищает диалог, `выход` завершает работу. `Ctrl+C` прерывает запрос.
JSON последнего ответа сохраняет текст, скорость и показатели памяти.
Лимит контекста включает запрос и ответ; старые полные пары сообщений
удаляются при заполнении. Незавершённые рассуждения не добавляются в историю.

## Память и ограничения

`--cache-gib` задаёт постоянный GPU-кэш матриц, `--host-cache-gib` — RAM-кэш.
`-1` включает автоматический выбор, `0` отключает соответствующий кэш.
Это лимиты кэшированных матриц, а не всей памяти процесса.
Эксперты загружаются по требованию, а не целым слоем.

Поддерживается одна GPU и один движок в процессе. Только архитектура
`GlmMoeDsaForCausalLM`: GLM-5.3-Flash не поддерживается. Нет сервера API,
обработки изображений, выполнения инструментов, сэмплинга и MTP.
Linux не проверен. Подробности, воспроизводимые тесты и исходный замер —
в [основном README](../README.md).
